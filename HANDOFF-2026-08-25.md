## 1. What this project is

**SpeakStone Narration** (formerly "Quest Reader Addon") is a World of
Warcraft addon that plays AI-generated voiceovers for quest text, gossip and
books, cloned per-NPC from that NPC's own in-game dialogue (F5-TTS). A
companion website (**Speakstone**, speakstone.beanw.co.uk) collects quest/
gossip/item text that players' game clients capture, screens it, and turns it
into a synthesis queue.

Two repos, two purposes, do not confuse them:

- **`questwow`** (this directory) — the private build workspace. Audio
  library, voice bank, the whole Python generation pipeline, harvest data.
  Never publish this wholesale.
- **`speakstone`** — the website. Next.js + Supabase (Postgres). Separate
  machine role, separate repo, separate GitHub remote.

## 5. The pipeline, script by script (all in `tools/`)

| Script | Does |
|---|---|
| `missing_quests.py` | Diffs client's quest table (`QuestV2`) against what's already voiced → produces an ID list |
| `wowhead_quests.py` | Fetches quest text + speaker from Wowhead for those IDs (rate-limited, 1.5s+ between requests — **never remove this pacing**, a past incident hit a rate limit from concurrent fetches) |
| `harvest_by_expansion.py` | The currently-running harvester — walks IDs, resolves expansion via `quest_expansions.json` + Wowhead cache, writes `harvested_*.json` |
| `QuestReaderHarvester/` | The **retired** standalone in-game addon for live capture. Superseded today by `Harvester.lua` built into the base addon — still works if installed, but the base addon's own capture (on by default) covers the same ground now |
| `harvest_export.py` | Converts a harvester capture into `passages.json` |
| `npc_traits.py` | Resolves NPC race/sex from client tables (`Creature`→`CreatureDisplayInfo`→`CreatureDisplayInfoExtra`). **Updated today**: now also accepts `--observed <speakstone_export.json>` — live-client-reported traits from players, used when the datamined tables have nothing (new NPCs, or NPCs with no extended display record) |
| `voice_sources.py` | Finds which NPCs have usable Blizzard reference audio |
| `voice_bank.py` | Assigns a stand-in voice to NPCs with none of their own, grouped by race/sex. **Updated today**: `--observed` flag passes through to `npc_traits.resolve()` |
| `synthesize.py` | Generates the actual audio via F5-TTS. `--nfe-step 16` is the quality/speed tradeoff currently in use for this batch |
| `build_soundlengths.py` | Rebuilds the length index. **Never run with `-o` pointed at the live `SoundLengths.lua` without a backup** — use `run_batch.py --install` instead, which has a shrink-guard |
| `build_sound_packs.py` | Splits `Sounds/`+`SoundLengths.lua` into per-expansion pack addons. **Updated today**: packs now inherit `## Version` from the base `.toc` automatically |
| `publish_packs.py` | Pushes built packs to their own GitHub repos, and (via `refresh_main_repo()`) the base addon to `SpeakStone-Quest-Reader-Main`. **Updated today**: skip-list now excludes `tools/`, `docs/`, backups, and agent `.md` files from what gets published |
| `run_batch.py` | Orchestrates a generation batch end-to-end, including `--install` (safe SoundLengths merge) and `--tell-speakstone` (POSTs completions back to the website) |
| `convert_library.py` | Shrinks WAV→OGG. **Exits non-zero for "nothing to do" — this is not a failure**, don't treat it as one |
| `pronunciations.json` | Lexicon for name pronunciation, loaded **longest-key-first** — load-bearing, some names are prefixes of longer ones |
| `quest_expansions.json` | The quest→expansion mapping. Currently ~38k entries and **growing live** from the running harvest — do not treat any snapshot of this as final while the harvest job is running |

Full detail: `tools/README.md` (kept in the private workspace only, stripped
from the public addon repo today).

## 8. Non-negotiable safety rules (collected from CLAUDE.md files, still true)

- **Never run two GPU synthesis processes concurrently.** VRAM-bound.
- **Never overwrite `SoundLengths.lua` without a backup and a shrink-guard.**
  Use `run_batch.py --install`.
- **Never delete `Sounds/` or `SoundLengths.lua` from `questwow`.** They are
  the pack builder's only input. Stripping audio is an *install/packaging*
  step applied to a copy in `AddOns`, never a repo edit.
- **`Sounds/` originals are never auto-deleted after Ogg re-encode.** That's
  the owner's call after confirming playback in-game.
- **Angle brackets in quest text mean two different things.** Beside
  dialogue, `<...>` is a stage direction, drop it. Wrapping the *entire*
  passage, it's item/object text, strip brackets but keep the words.
- **`max: 1` on the Postgres pool is wrong** against Supabase's transaction
  pooler — causes hangs. Pool is `max: 5`, do not "optimize" it down.
- **A non-zero exit from `convert_library.py` isn't always failure** — it's
  normal for "nothing to do".
- **Never fetch Wowhead's listing/search endpoints** (403s immediately). Use
  cached per-quest pages + zone-based inference instead.
- **Rate-limit discipline on Wowhead**: serial, 1.5s+ between requests, stop
  on 403/429, never retry in a tight loop.
- **Creature GUID parsing**: `strsplit("-", guid)` via `pcall` needs **7**
  return values after `ok` (not 6) to reach `creatureID` — `pcall` returns
  its own success flag first. Got this wrong earlier today, fixed everywhere
  (addon, harvester, playback path) — if you see this pattern anywhere else,
  check it.
- **Before any GitHub push to the addon**, confirm you're pushing to
  `SpeakStone-Quest-Reader-Main`, not the retired `QuestReaderAddon`. See §3.
- **Before running `publish_packs.py`**, re-read it — it was fixed today to
  stop leaking `tools/`/`docs/`/backups into the public repo. If your copy
  predates today's fix, don't run it against the live repo without checking.
